# STYLE.md template: measure a repeating format before you copy it

Use when 5+ proven videos share a format. Every number is measured (ffprobe, whisper word counts, scene detection,
one-frame-per-second counts), never guessed. List the source set (links) at the top.

## The pattern (one numbered line each, with "N of M sources" counts)
1. First frame: face or graphic? (Our rule: face from frame 1, always.)
2. Layout: full face, split (panel top / face bottom, seam y), green screen, desk shot. Ratio per source.
3. Hook: length in words, seconds to finish it, anchor used (price, brand, secret, big number, authority, a job that got "killed").
4. When the asset is named and "free" is said (seconds).
5. Escalation ("it is not one, it is N") and list pace (seconds per item).
6. Second hook position (% of runtime) and what follows it (a real demo).
7. Install / how-to line near the end.
8. CTA: keyword, how it is shown, comments vs likes ratio.
9. Pace by format (words per second), longest pause.
10. Visual change cadence (seconds per new visual), cuts vs zooms.
11. Caption style(s): font, case, size, box, position, words per chunk.
12. Real UI vs rebuilt graphics; which logos appear.
13. Audio: loudness, music bed or not.
14. Length range and the sweet spot.
15. Your layer on top: your rules (face first, both CTA endings, no invented numbers, 3 hook types).

## Framing and pace quick reference
Seam position, face window, eye line, pace per format, length per format, loudness.
