# Matching a reference, banners and square ads

## When the user sends a reference image

Rejected drafts usually came from making something "inspired by" a reference
instead of mapping it.

1. Find the exact image (attachment, URL, recent downloads). If there are
   several candidates, make a contact sheet and confirm which one.
2. Write down its structure before designing: canvas and background tone,
   where the brand mark sits, headline lines and which word is emphasised (and
   in what colour), portrait placement and crop, geometric shapes behind the
   portrait, icon count and style, texture.
3. Generate a **blank template** with the image model: same structure, but
   no people, no faces, no text, no logos, with clean space for each.
4. Add the real portrait, the text and real logos in code.
5. QA against the reference side by side: does it resemble it in structure,
   or only in topic? Is the brand mark readable (font fallbacks make it tiny)?
   Any UI artifacts (video time badges) in the portrait crop?

## Community / course banners (wide covers)

- Clean structure beats dark "AI dashboard" visuals unless the reference is dark.
- Headline: 2 lines, left-aligned, one emphasised phrase in the accent colour.
- Tool icons as clean rounded tiles without labels; labels next to tiles tend to overlap.
- Portrait large on one side, over angled colour blocks.
- Send a preview; publish nothing until the user approves.

## Square paid-social ads (1080x1080 or 1200x1200)

The buyer must recognise three things while scrolling: the brand, that it is
for their category, and the outcome. Hierarchy:

1. brand lockup, unmistakable at phone size (not a watermark)
2. category line ("FOR <YOUR BUYER>"), large and heavy: it is a recognition signal, not an eyebrow
3. one outcome headline
4. short support copy
5. proof (only marks you have written permission to use)
6. destination, visible but secondary

Revision pattern: keep the previous version, enlarge a watermark-sized lockup
35 to 55%, close dead vertical gaps, size proof logos optically (long marks
need more width), remove decorative counters. Check at a real 320 to 400 px
feed size; a mechanical PASS does not override what the pixels show. A square
feed ad is not a Stories/Reels ad: make a vertical version or restrict placements.
